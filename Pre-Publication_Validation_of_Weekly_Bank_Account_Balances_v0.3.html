Why this is a HyperUnit

It Preserves an Ongoing Responsibility, Not Just a Table

Turning a file into a web page does not automatically create a capability. Account validation becomes reusable, challengeable, and evolvable only when Identity, Responsibility, typed inputs, Outputs, and Reality validation remain explicit.

01 / IDENTITY

Logical Identity Does Not Change with the Filename

Replicas are portable, but the publication chain permits only one Authoritative Writable Instance at a time.

02 / RESPONSIBILITY

Responsible for Pre-Publication Completeness

It makes no unlimited claim about the truth of bank balances and does not replace the treasury role's final judgment.

03 / TYPED I/O

Inputs Preserve Their Epistemic Types

The account register and observed balances are Facts; rule thresholds are Configuration; validation conclusions are Claims.

04 / REALITY

Later Outcomes Form Evidence

Platform acceptance, error feedback, and supplemental-entry results become Reality Facts; they cannot retroactively rewrite a historical Claim.

How Pre-Publication Validation of Weekly Balances Works

This example combines the account register, a weekly balance snapshot, and versioned validation rules into a traceable Dependency Snapshot. The Capability forms only a validation Claim; it does not replace the responsible role in making the final publication Decision.

When you drag the data object on the right, the text recalculates readable line widths from the object's bounding box and wrap margin. Paragraphs yield space when the object enters the body area and flow back naturally when it leaves, instead of being permanently split into a fixed layout.

The table and chart use the same synthetic data. Double-click a table cell to edit its value; switching back to the chart redraws it locally from the latest data. No bank, Feishu, or external chart service is connected.

Dragging and resizing change only the layout state in this page's memory. To retain text, data, positions, sizes, and view choices, use "Save Local Copy As" or "Export Editable Copy" at the top.

Demo controls: without enabling global editing, grab the "⠿ Drag" handle at the top of an object to move it or drag the lower-right handle to resize it. Both actions support mouse, touch, and arrow keys. Double-click any canvas text to quickly edit the current paragraph; press Ctrl/Cmd+Enter to commit, Esc to cancel, or click away to commit. Global editing also enables table insertion, cell editing, and connectors. Connection mode does not trigger moving or resizing.

Decision Episode

Human Judgment Does Not Overwrite the System Baseline

A reviewable publication preserves more than whether it was sent. It retains the dependencies, original recommendation, human intervention, actual execution, and subsequent Reality.

01

Decision Baseline

The Capability forms the original publication recommendation from frozen dependencies.

02

Intervention

Record the proposer, authorization, time, new facts, and Declared Rationale.

03

Final Decision

The responsible role freezes the formal choice; the Baseline remains visible.

04

Execution

A controlled external system performs the real publication; this page does not.

05

Reality Fact

Platform acceptance, supplemental entries, and error feedback form later Facts.

06

Evidence

Connect the historical Claim to later Facts to support the next evaluation.

Governance boundary

Portable View Is Readable; the Optional Authoring Layer Can Edit and Connect, but Has No Elevated Privileges

Portable HTML is not inherently safe. This release deliberately narrows its capabilities: the Content Security Policy blocks background network access, external embedding, and form submission; the local authoring layer must be explicitly enabled; edits occur only in memory; and saving, exporting, or opening author-added links requires an explicit user action.

This Page Allows

  • View the public example in the default reading state and explicitly enable the local authoring layer
  • Insert and edit synthetic tables, switch local charts, and drag objects to observe text wrapping
  • Create adjustable relationship connectors and document links between modules
  • Run fixed synthetic scenarios in memory and simulate Decision and Reality validation
  • Explicitly save a non-authoritative editable replica or export a non-authoritative read-only snapshot

This Page Does Not Allow

  • Page scripts connecting in the background to banks, Feishu, ERP, APIs, or network services
  • Automatically reading, uploading, or persisting real account or balance files
  • Using IndexedDB or localStorage to silently overwrite page content
  • Performing real publication, payment, approval, or system writes
